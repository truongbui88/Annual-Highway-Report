# Annual-Highway-Report
Run [AHR data process.R](https://github.com/truongbui88/Annual-Highway-Report/blob/main/AHR%20data%20process.R) from start to finish to produce the data for the Annual Highway Report.  

## Output:
`AHR_data_2022.csv`: result of all metrics and final ranking for the year 2022.

`AHR_data_2021.csv`: 2021 data for reference

`change_2021_2022`: all values of year 2022 - values 2021. Just for comparison. 

`congestion_data_by_state_2022.csv`: congestion data by state for the year 2022. These includes value measured by INRIX and estimated values.  Estimated values are based on the relationship between INRIX's congestion hours and the number of auto commuter in metro areas. 

`congestion_data_by_state_2021.csv`: congestion data calculated by UMR for the year 2021.
